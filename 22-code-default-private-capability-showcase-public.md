# Code Default Private, Capability Showcase Public

The standard advice for building a public engineering profile is: open source everything. Push daily, keep the squares green, let the repos speak.

I went a different way, and it was a deliberate decision, so let me write it down.

My rule: code default private. Capability showcase public.

Almost everything I build stay in private repos. The automation platform. The investment system. The learning app for my kid. Anything that touch work. And this isn't because the code is embarrassing — it's because when I actually list out what the code contain, most of it was never mine to publish. Operational logic that map to real business processes. Strategy parameters tied to my own money. My kid's learning data. Things adjacent to employers and clients. None of that belong on a public internet, no matter how clean the code is.

And here's the thing I'd say to anyone hesitating on this: keeping those private is not a weakness in your public profile. It IS part of the profile. Someone who dump everything employer-adjacent into public repos is showing future employers exactly what will happen to their code too. Knowing what not to publish is a professional signal, not a gap.

But then — if the code is private, what's public? For a while my answer was "nothing," and that was the real mistake. Private code plus silence just look like nothing happened.

What I settled on: the judgment go public, the implementation stay private.

Because think about what a public repo actually communicate to a stranger. Nobody read fifty thousand lines. At best they skim a README and check if commits are recent. The code prove I can type. It prove very little about whether I can decide — where a boundary go, what a rule engine should refuse to own, when a boolean flag is hiding a domain concept. That's the part worth showing, and it turn out that part can be shown completely without a single line of production source.

So the public layer is this journal. Design smells I found, how I re-modeled, what principle came out. Every entry desensitized — patterns are public, systems are not. The green squares stay on (private contributions show activity without content), the profile state the positioning in one line, and the journal carry the proof.

You're reading the strategy right now, by the way. This is day 22 of it running.

Show the code, and people learn what you built.

Show the judgment, and people learn what you'd do with theirs.
